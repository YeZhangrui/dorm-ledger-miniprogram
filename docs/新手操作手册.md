## 1. 第一步：确认你有自己的小程序 AppID（5 分钟）

AppID 是小程序的身份证，必须是你自己账号下的，否则上传不了、也备案不了。

**查你账号里的 AppID**

1. 电脑打开 <https://mp.weixin.qq.com>，用你注册小程序的微信扫码登录
2. 左侧菜单 → **设置** → **基本设置**
3. 页面向下找到「**账号信息**」，里面有一行 **AppID(小程序ID)**，形如 `wx1234567890abcdef`，复制它

**和项目里比对**

1. 打开微信开发者工具，打开项目 `D:\小组作业\miniprogram`
2. 右上角 **详情** → **基本信息**，看 **AppID** 一栏
3. **两边一样** → 跳过；**不一样** → 把项目里的 AppID 换成你的（告诉我，我改）

> 还没有小程序账号？去 <https://mp.weixin.qq.com> 点「立即注册」→ 选「小程序」→ 邮箱 + 个人身份证（免费，个人主体即可，不需要营业执照）。

## 2. 第二步：开通云开发，拿到环境 ID（10 分钟）

云开发是微信提供的"免费后端"，数据库和云函数都放在里面。

1. 微信开发者工具打开项目
2. 点**顶部工具栏的「云开发」按钮**（一朵云的图标，在「上传」「版本管理」旁边）
3. 第一次会弹「开通云开发」→ 点 **开通** → 同意协议
4. 弹出创建环境：
   - **环境名称**：填 `dorm-dev`（名字随意，记住就行）
   - **套餐**：选**基础版**（有免费额度，一个寝室完全够用）
   - 点 **创建**，等 1–2 分钟
5. 创建完会进入「云开发控制台」。点左上角环境名旁边的 **设置** → **环境 ID** → 复制那串字符
   形如：`dorm-dev-8g1abcde2f3g4h`
6. 回到开发者工具的代码编辑区，打开文件：`miniprogram/config/env.js`
7. 找到这一行：

   ```js
   develop: '',   // 开发版
   ```

   把环境 ID 粘进去（注意保留单引号和逗号）：

   ```js
   develop: 'dorm-dev-8g1abcde2f3g4h',   // 开发版
   ```

8. 保存文件 → 在开发者工具按 **Ctrl + R** 重新编译

**成功标志**：底部 Console 面板里**不再出现**「未配置云环境 ID，走本机存储模式」这句话。

> 不想自己改文件也行：把环境 ID 发我，我改。

## 3. 第三步：建 5 个数据库集合 + 改权限（10 分钟）

数据库就是账本存放的地方，要建 5 个"抽屉"，名字必须一模一样。

**建集合**

1. 云开发控制台 → 左侧 **数据库**
2. 点集合列表旁的 **+** → 输入集合名 → 确定，重复 5 次，建这 5 个：

   | 集合名 | 存什么 |
   |---|---|
   | `rooms` | 房间（房间码、房主） |
   | `room_members` | 房间里有哪些人 |
   | `expenses` | 每一笔账 |
   | `settle_logs` | 结清记录（谁什么时候还了钱） |
   | `usage` | AI 每天用了几次（防刷） |

3. 名字必须**全小写、带下划线**，打错一个字母都会报错

**改权限（很重要，5 个都要改）**

1. 点某个集合 → 右上角 **...** 或 **权限设置**
2. 选「**仅管理端可读写**」→ 保存
3. 5 个集合全部改成这个

> 这个权限的意思是：手机端不能直接读写数据库，必须通过云函数（相当于"只能通过柜台办事，不能自己开抽屉"）。安全。

**索引暂时不用建**（性能优化用的，等能用起来再补，我把清单留着）。

## 4. 第四步：上传 5 个云函数（15 分钟）

云函数就是"柜台后面办事的人"，要一个个传到云上。

**4.1 先确认/补齐"公共代码"（大多数情况可以跳过）**

展开 `cloudfunctions` 文件夹，看 `login`、`room`、`expense`、`ai`、`backup` 这 5 个里面**是不是都各有一个 `shared` 文件夹**：

- **都有** → 跳过这一步，直接去 4.2（我已经跑过了）
- **没有 / 缺几个** → 在 `D:\小组作业\tools\` 里双击 **`prepare-cloudfunctions.cmd`**

双击后会弹出一个黑窗口，显示：

```
[1/2] Copying shared modules into each cloud function ...
  [OK] login\shared
  [OK] room\shared
  [OK] expense\shared
  [OK] ai\shared
  [OK] backup\shared
```

看到 5 个 `[OK]` 就按任意键关掉。
（这一步是把公共代码复制进每个函数目录，**缺了的话上传后会报"找不到模块"**。以后只要改了公共逻辑，就要重新双击一次。）

**4.2 在开发者工具里选环境**

1. 左侧「资源管理器」找到 `cloudfunctions` 文件夹
2. **右键** `cloudfunctions` → **当前环境** → 选你刚才建的环境（`dorm-dev`）
   （如果这个菜单里没有「当前环境」，点顶部「云开发」按钮，在打开的窗口里切换环境也一样）

**4.3 逐个上传**

依次**右键**下面 5 个文件夹 → 点「**上传并部署：云端安装依赖（不上传 node_modules）**」：

```
login → room → expense → ai → backup
```

每个等它弹「上传成功」再点下一个（第一次装依赖会慢一点，单个 30 秒到 2 分钟都正常）。

**4.4 检查**

云开发控制台 → 左侧 **云函数** → 应该能看到 5 个函数名，状态正常。

## 6. 第六步：平台流程（今天就启动，等得最久）

这几项在 <https://mp.weixin.qq.com> 后台做，**只有账号主人能提交**，而且审核要等。

| 顺序 | 事项 | 大致位置 | 要准备什么 | 等多久 |

| 1 | **小程序备案** | 设置 → 基本设置 → 小程序备案 | 身份证、手机号、人脸核验、承诺书 | **1–3 周（最慢，先做）** |

## 8. 卡住了怎么办（对照表）

| 你看到的 | 原因 | 怎么办 |
|---|---|---|
| 点「云开发」提示未注册 / 无权限 | 账号还没开通云开发 | 回 §2 第 2–4 步 |
| 上传云函数报「找不到模块 `./shared/...`」 | 没跑准备脚本 | 回 §4.1 双击脚本，再上传 |
| 上传报「依赖安装失败」 | 网络抖动 | 重试一次；还不行选「上传并部署：所有文件」 |
| 云函数调用报 `FUNCTION_NOT_FOUND` | 没上传 / 环境选错 | 检查 §4.2 选的环境、§4.4 是否有 5 个函数 |
| 数据库报 `permission denied` | 集合权限没改 | 回 §3 把 5 个集合权限改成「仅管理端可读写」 |
| Console 一直提示「未配置云环境 ID」 | env.js 没填或没保存 | 回 §2 第 6–8 步 |
| 云函数报超时 | `ai` 函数超时没改 | 回 §5 第 3 步改成 60 秒 |
| 找不到某个按钮 | 开发者工具版本不同 | **截图发我**，不要乱点 |
