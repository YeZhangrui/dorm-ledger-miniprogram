## 一、先修的那个显示 bug：首页头部压住状态栏和系统胶囊

**现象**（截图反馈）：首页顶部的 📒 和「4 人寝室 · 公共开支台账」被状态栏、右上角胶囊（··· ⊙）压住，左侧图标被裁掉一截。

**根因**：首页用了 `"navigationStyle": "custom"`，微信不再给顶部留状态栏，而样式里只写了 `padding-top: env(safe-area-inset-top)`；在开发者工具/部分机型上该值为 0，且**胶囊位置从来不会自动让位**。原来品牌区还和「成员 / 演示数据 / 清空 / ⌃」挤在同一行，右侧直接顶到胶囊底下。

**改法**

| 改动 | 文件 |
| --- | --- |
| 新增 `utils/layout.js`：用 `wx.getWindowInfo()` + `wx.getMenuButtonBoundingClientRect()` 算出 `statusBarHeight`、`navBarHeight`、`capsuleReserve`（胶囊左侧到屏幕右边的宽度 + 8px 呼吸缝），老基础库/平板拿不到胶囊时按 20/44/104 兜底 | `utils/layout.js`（新增） |
| 首页把头部拆成「导航行（图标+品牌小字，右侧按 `capsuleReserve` 留白）→ 标题区 → 操作按钮行」，`padding-top` 由 JS 写入 px；横竖屏切换时重新测量 | `pages/index/index.wxml` / `index.js` / `index.wxss` |
| 操作按钮整行排到品牌下方，图标按钮换行时 `⌃` 固定靠右 | `pages/index/index.wxss` |

> 只让「状态栏高度」是不够的：胶囊悬浮在导航行右侧，必须同时留出 `capsuleReserve`，否则标题仍会被压住。

## 二、二级菜单和一级菜单统一

**先把两个层级定清楚**

- **一级菜单**＝底部原生 tabBar（首页 / 记账 / 小票 / 明细 / 提醒）。
- **二级菜单**＝页面内的分段切换：「明细」的全部/未结清、「记账」的等额平分/按住宿天数、「提醒」的语气三选一。

**之前的问题**

1. `.seg` 是「灰底 `#efede5` + 选中项白底」，而页面底色是 `#f3f1ea` —— 容器几乎和背景同色，选中态白底对比只有 **1.13:1**，等于看不出选中的是哪个。
2. tabBar 图标是 `#93a2b7`（蓝灰）、文字是 `#5f6c64`（墨绿），选中图标 `#0f9d75` 和文字 `#116e56` 也不是同一个绿 —— 一级菜单自己就有两套颜色，图标对比只有 2.5:1。
3. 「提醒」的语气用原生 `picker`，和分段控件是两种交互语言。
4. 「明细」的分段被塞进页头右侧，和「记账」的分段位置不一致。

**现在**

| 位置 | 做法 |
| --- | --- |
| `.seg`（明细 / 记账） | 统一成胶囊分段：容器 `--surface-2` + 发丝描边；**选中＝品牌绿 `#116e56` 实底 + 白字（6.2:1）**，未选中＝`--ink-2`（10:1）；圆角和 `.pill`/`.icon-btn`/`.room-pill` 同一套胶囊语言 |
| `.tone-picker`（提醒） | 停用原生 picker，改成三列分段卡：选中同样是品牌绿实底白字，副标题 `rgba(255,255,255,.92)` |
| tabBar | 图标按 `app.json` 的文字色重新上色：未选中 `#55625b`、选中 `#116e56`，**图标与文字同色**；`borderStyle` 改 `black` 让底部栏和纸色背景有分界线 |
| 位置 | 页面级筛选（明细）放页头下方整行；表单内选项（记账的分摊方式、提醒的语气）放卡片内整行 —— 语义不同但视觉同源 |
| 二级页面 | 「房间码」补上和其它页一致的 `.page-head`（大标题 + 一句说明）；tab 页的导航栏标题统一为品牌名「寝室公共开支台账」，避免和页内大标题重复两遍 |

### 2.1 所有下拉统一成一个自绘组件

**问题**：原生 `<picker mode="selector">` 在小程序里渲染的是**系统弹层**（取消/确定 + 灰色滚轮），样式完全不受页面控制。它还有个更直接的毛病：「找谁」的选项是一长串「陈默 欠 赵小满 ¥15.00（含对冲 ¥0.00）」，塞进滚轮后整屏灰字、读起来非常费劲，和页面上其它控件完全不是一套语言。

**做法**：新增组件 `components/sheet-select`，三页复用，替换掉**全部 5 处**原生下拉。

| 页面 | 原来的控件 | 现在 |
| --- | --- | --- |
| 记账 | 类别 / 垫付人（原生 picker） | `<sheet-select>` |
| 小票 | 服务商 / 垫付人（原生 picker） | `<sheet-select>` |
| 提醒 | 找谁（原生 picker） | `<sheet-select>`（带 `desc` 明细与 `side` 金额） |
| 提醒 | 语气 | 保持三列分段卡（本来就不是下拉） |
| 明细 / 记账 | 全部/未结清、等额/按天 | 保持 `.seg` 分段 |

组件的视觉规则：

- **触发器**和输入框一模一样（白底、发丝描边、右侧 `⌄`），所以「金额 / 项目 / 类别 / 垫付人」排在一起是齐的；
- **面板**是白色圆角卡 + 拖拽短横 + 标题行（标题 + 「N 项」），每行「主文案 / 说明 / 右侧金额」；
- **选中行**＝品牌绿描边 + 品牌浅底 + `✓`，和 `.seg`、tabBar 的"选中＝绿"一致；
- **点行即选**，不用再点"确定"；点遮罩或「取消」退出；
- 选项为空或 `disabled` 时点触发器只弹 toast 说明原因，不会打开空面板。

> 兼容性：组件用 `styleIsolation: 'apply-shared'`，外观样式自带、只继承 `app.wxss` 的颜色变量，所以换皮肤时不用改组件。事件统一 `bind:change`，`detail = { index, option }`；页面里的 `onCat` / `onPayer` / `onPreset` / `onWho` 已从读 `e.detail.value` 改成读 `e.detail.index`。

## 三、对比度：量化 + 修到位

**口径**：WCAG 2.1；正文/小字 ≥ 4.5（AA），大字（≥24px 或 ≥18.66px 粗体）≥ 3，AAA 为 7。审计脚本把半透明前景、头部渐变（含金色光斑）、`opacity` 都先合成到底色再算。

**结果**：70 条组件组合（含新增的下拉组件），**AA 不合格 0 条**（改前 2 条），30 条 AA、40 条 AAA。改前最差的是「已退出」成员的姓名 4.11 和徽标 3.21，根因都是 `.person.out{opacity:.72}`。

**改了这些**

| 令牌 / 组件 | 改前 → 改后 | 原因 |
| --- | --- | --- |
| `--ink-2` | `#48564e` → `#3c4942` | 小字标签、按钮文字整体加深 |
| `--ink-3` | `#5f6c64` → `#55625b` | 说明文字 5.1 → 6.4 |
| `--ink-4`（新增，占位符） | `#64706a` → `#5c6761` | 微信默认 placeholder 只有约 2.1:1；现在 5.8 |
| `--danger` | `#a33a3a` → `#9c3636` | 红字在浅红/浅灰底上 5.0 → 6.2/6.5 |
| `--gold-ink`（新增） | 品牌小字改用 `#efe1c5` | 金色小字叠在带金色光斑的深绿上 4.8 → 7+ |
| `--on-header-2` | 72% → 80% 白 | 头部副标题、状态行 |
| `.person.out` | **删掉整体 `opacity:.72`** | 改用「姓名降为 `--ink-3` + 徽标不透明浅底」，姓名 4.11 → 6.4，徽标 3.21 → 6.4 |
| `.tag` | `--ink-3` → `--ink-2` | 明细页参与人标签更实 |
| 所有 `input` / `textarea` | 新增 `placeholder-class="ph"`（`--ink-4`） | 占位符统一可读颜色 |

> 仍停在 AA（约 5.4–6.3）的是「品牌绿 `#116e56` 做底/做字」那一族。要把它们推到 AAA 需要把品牌绿压暗到 `#0e5b47`，会改动品牌色，所以按 AA 收口，未动品牌色。

## 七、你在开发者工具里需要确认的 4 处

1. 首页顶部：📒 和标题完整、不被状态栏/胶囊压住；「成员 / 演示数据 / 清空」在第二行，`⌃` 在最右。
2. 明细页：页头下方是整行分段，「全部」是绿底白字的选中态。
3. 提醒页：「语气」是三张并排卡片，选中项绿底白字。
4. 任意下拉（记账的类别/垫付人、小票的服务商/垫付人、提醒的找谁）：点开应是白色圆角面板 + 每行「文案 / 说明 / 金额」+ 当前项绿框和 `✓`，点一下就选中并收起；**不应再出现系统的灰字滚轮和"取消/确定"**。

真机上如果换了机型（尤其 iPad、折叠屏），头部高度会按 `wx.getMenuButtonBoundingClientRect()` 自动重算，不需要再改样式。
